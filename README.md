One-line office joke, judged head to head. The entry program writes a single
joke about office life to `/output/entry.txt` and verifies it against the
bounty's gate (UTF-8, 1–200 characters, one line, not whitespace-only).

The joke:

> Our printer only jams when the deadline is real, which is how I learned it reads the calendar.

SCREENING.md scores 12 candidate jokes against the judge brief's five
criteria, in order, and picks this winner.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-joke-out node main.ts
cat /tmp/office-joke-out/entry.txt
```

Requires Node 22.18 or later (main.ts runs as plain TypeScript).
